# Rupor 📣

iOS-приложение-«рупор»: зажми кнопку, скажи что-нибудь — отпусти, и голос сразу повторится через динамик с эффектами.

## Возможности
- Push-to-talk: удержание — запись, отпускание — мгновенное воспроизведение
- Пресеты голоса: Обычный, Рупор, Бурундук, Монстр, Робот, Эхо, Зал, Замедление
- Ручная настройка войсченджера: высота тона, скорость, фильтр мегафона, искажение, эхо, реверб, громкость
- Повтор последней записи, индикатор уровня, хаптика

## Сборка
Нужны Xcode и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```sh
./build_ipa.sh   # -> Rupor.ipa (неподписанный)
```

Готовый неподписанный IPA лежит в Releases. Подпиши его через AltStore / Sideloadly / TrollStore и т.п.

Минимальная версия iOS: 17.0.
